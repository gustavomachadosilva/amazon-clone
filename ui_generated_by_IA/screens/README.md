# Screens

Each file here is one screen extracted from [`../Mercatto.dc.html`](../Mercatto.dc.html) — same
header/footer chrome, same markup, same `{{ }}` template syntax and `<sc-for>`/`<sc-if>` tags,
just isolated so a single screen is easy to open and read without scrolling the combined file.

These are **not runnable pages** — the template bindings aren't interpreted outside the original
prototype runtime (see `../README.md`, "About the Design Files"). Read them for structure, copy,
and exact values, the same way you'd read `Mercatto.dc.html` itself.
