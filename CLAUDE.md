# Mercatto

A marketplace project (Amazon-like) being built for a college course. No application code yet —
stack and architecture are undecided; don't assume a framework or scaffold one without asking.

## What exists

- `ui_generated_by_IA/` — design material: an HTML prototype (`Mercatto.dc.html`) and a design
  system/token set (`design-system/`). This is raw input for a planned pass to organize it into
  real UI files — treat it as reference material, not an approved spec to implement against,
  unless told otherwise.
